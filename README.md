# LIFE//OS

LIFE//OS is an AI-powered gamified personal operating system that transforms real-world goals, habits, learning, fitness, and productivity into personalized quests and progression.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy environment variables:
   ```bash
   cp .env.example .env
   ```
3. Set your `GEMINI_API_KEY` and Firebase credentials in `.env`.
4. Run the development server:
   ```bash
   npm run dev
   ```
